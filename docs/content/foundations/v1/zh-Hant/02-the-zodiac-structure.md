# 黃道：元素與模式

## 導讀

黃道是一套由十二個黃道星座區段構成、用來組織位置的占星術座標詞彙。在本課程中，這個圓被分成十二個各三十度、依序以牡羊座至雙魚座命名的等分區段。命盤中的天體落在某個黃道星座時，便會取得一個位置，以及一組可供探索的傳統聯想。

每個黃道星座都屬於一種**元素**——火、土、風或水——以及一種**模式**，也稱為模態或性質——本位、固定或變動。它們為星座象徵提供不同面向，不是性格框框，也不是預測。

## 核心概念

### 十二個黃道星座形成循環結構

十二個黃道星座名稱依循重複的順序。每個星座都有一種元素與一種模式：

| 順序 | 黃道星座 | 元素 | 模式 |
| ---: | --- | --- | --- |
| 1 | 牡羊座 | 火 | 本位 |
| 2 | 金牛座 | 土 | 固定 |
| 3 | 雙子座 | 風 | 變動 |
| 4 | 巨蟹座 | 水 | 本位 |
| 5 | 獅子座 | 火 | 固定 |
| 6 | 處女座 | 土 | 變動 |
| 7 | 天秤座 | 風 | 本位 |
| 8 | 天蠍座 | 水 | 固定 |
| 9 | 射手座 | 火 | 變動 |
| 10 | 摩羯座 | 土 | 本位 |
| 11 | 水瓶座 | 風 | 固定 |
| 12 | 雙魚座 | 水 | 變動 |

這張表是結構參照，不是描述一個人必然如何思考、感受或行動。更完整的討論也會考慮天體、宮位、相位、方法與個人脈絡。

### 黃道星座與天文星座是不同系統

天文星座是具有正式界線的天空區域。國際天文學聯合會承認 88 個天文星座，而它們的界線大小並不相等。這些天文星座不會與十二個等分的黃道星座區段一一對齊。

占星術中的黃道星座，是占星術框架中的位置區段；天文星座則是天文學上的天空區域慣例。兩者名稱可能重疊，但界線與用途並不相同。

NatalNode 目前使用**熱帶黃道**來組織星座位置。這不會把黃道星座變成天空中的實體，也不要求學習者研究計算演算法。

### 元素：四種占星術觀察角度

在占星術中，元素是一種傳統分組方式：將三個星座歸為一組，並描述其象徵的一個面向。元素詞彙可以幫助學習者提出問題：某個星座通常與哪一類能量或經驗相關？

| 元素 | 黃道星座 | 傳統聯想 |
| --- | --- | --- |
| **火（Fire）** | 牡羊座、獅子座、射手座 | 活力、主動性、表達、行動與啟發 |
| **土（Earth）** | 金牛座、處女座、摩羯座 | 物質性、穩定、實用性、具身性與可觸及的成果 |
| **風（Air）** | 雙子座、天秤座、水瓶座 | 思考、溝通、連結、概念，以及社會或智性的交流 |
| **水（Water）** | 巨蟹座、天蠍座、雙魚座 | 感受、敏感、接納，以及情緒或想像性的經驗 |

這些是占星術上的聯想，不是經驗科學上的人格類別。火元素的落點不會讓每個人都精力充沛，水元素也不會診斷一個人的感受。元素只是眾多觀察角度之一，仍須以天體、宮位、相位、傳統與脈絡加以限定。

### 模式：星座參與變化的三種方式

模式描述星座象徵的另一個面向。它們常被教導為黃道中的一種節奏：

| 模式 | 黃道星座 | 傳統強調 |
| --- | --- | --- |
| **本位（Cardinal）** | 牡羊座、巨蟹座、天秤座、摩羯座 | 發起、開始、動員或引導變化 |
| **固定（Fixed）** | 金牛座、獅子座、天蠍座、水瓶座 | 維持、穩定、集中或保持方向 |
| **變動（Mutable）** | 雙子座、處女座、射手座、雙魚座 | 適應、轉換、分配或調整以因應變化 |

這是傳統的占星術詞彙，不是用來測驗某人是否果斷、固執或反覆不定。只有放在命盤與明確說明的方法中，模式才具有意義。

### 元素 × 模式是學習的重點

元素與模式回答的是不同問題。將兩者結合，可以在不把星座變成完整人物檔案的情況下，對它提供簡潔描述。

| 組合 | 初學者對兩個面向的讀法 |
| --- | --- |
| **火 + 本位**（牡羊座） | 同時考慮元素的主動性與表達，以及模式對開始或動員的強調。 |
| **土 + 變動**（處女座） | 同時考慮實際、可觸及的象徵，以及模式對適應或改進的強調。 |
| **風 + 固定**（水瓶座） | 同時考慮思考與連結，以及模式對維持或集中的強調。 |
| **水 + 本位**（巨蟹座） | 同時考慮感受與接納，以及模式對發起或引導變化的強調。 |

這些是組合式提示，不是決定論的人格摘要。先分別理解兩個傳統概念，再詢問完整命盤如何支持或使它們變得更複雜。

### 關於極性的說明

有些傳統加入一條極性軸，將星座配對為**陽性／陰性**或**主動／接納**。不同學派使用的標籤各異，也不是道德評比。Foundations V1 將極性視為可選的補充說明，而不是主要軸線、練習要求或 NatalNode 產品欄位。

### 分類是起點，不是判決

這些表格幫助學習者辨認黃道模式。它們不會確立固定氣質、保證結果，也不是科學分類。不同學派對星座、天體、宮位、角點與相位的權重各有不同；請先從共同結構開始，並說明所採用的慣例。

## 專業詞彙

- **黃道** — 用於在黃道上組織位置的占星術框架。
- **黃道星座** — 本課程黃道框架中的十二個具名區段之一。
- **熱帶黃道** — NatalNode 目前使用、面向占星術的黃道框架。
- **元素** — 四種傳統星座分組之一：火、土、風或水。
- **模式／模態** — 三種傳統星座分組之一：本位、固定或變動。
- **占星術聯想** — 用來探索某個星座分組的傳統意義或主題。
- **天文星座** — 具有界線、且不同於本課程等分黃道星座區段的天文天空區域。

這些詞彙用來組織星座象徵。它們不是固定人格類型的標籤。

## 範例

假設一張合成的教學卡片要求你分類牡羊座、處女座、水瓶座與巨蟹座。結構上的答案是：牡羊座 = 火 + 本位、處女座 = 土 + 變動、水瓶座 = 風 + 固定，以及巨蟹座 = 水 + 本位。

將其中一組讀成兩個面向。以處女座為例，土元素提供實用性與具身性等傳統詞彙，而變動模式提供適應與改進。占星家可以把這些想法當作問題，再考慮天體、宮位、相位、傳統與經驗。這種分類不能證明一個人很實際，也不能證明一個人適應力強。這就是之後支持「行星 × 星座 × 宮位」的組合邏輯。

## 我的命盤

開啟**我的命盤**，觀察實際回傳的星座標籤。

- **命盤存在：**辨識星座，以及在有顯示時辨識黃道模型標籤。使用上表按元素與模式分類，將其作為傳統詞彙使用，而不是診斷；不要用對天文星座的猜測取代回傳的星座。
- **命盤不存在：**如果想檢視某個落點，使用產品正常的建立或計算流程。如果練習不要求命盤，就使用上面的星座表。不要捏造天體、星座、度數或詮釋。

先學會黃道如何組織，再提出詮釋問題。

## 練習

完成以下分類與綜合練習，但不要寫成人格診斷：

1. 填寫巨蟹座的元素與模式。
2. 填寫射手座的元素與模式。
3. 說出屬於「風 + 本位」的星座，以及屬於「土 + 固定」的星座。
4. 選擇一個屬於「火 + 變動」的星座。分別描述元素面向與模式面向，再用一句謹慎的占星術句子將兩者結合。
5. 解釋為什麼元素與模式的分組不能對一個人作出決定論的主張。

參考答案：巨蟹座是水 + 本位；射手座是火 + 變動；天秤座是風 + 本位；金牛座是土 + 固定。綜合時，將火元素的活力或表達詞彙，與變動模式的適應詞彙分開，再將這一組描述為需要完整命盤與脈絡的詮釋角度。

## 理解檢核

### 問題 1

哪一項陳述最能區分黃道星座與天文星座？

- A. 它們是完全相同的等大區域，只是有兩種名稱。
- B. 黃道星座是占星術的位置區段；天文星座是具有不等界線的天文天空區域慣例。
- C. 天文星座是人格類別，而黃道星座是物理恆星。
- D. 命盤只能使用天文星座，永遠不使用黃道星座。

**正確答案：**B。

**解釋：**兩個系統可能共享名稱，但界線與用途不同。將它們分開，能釐清命盤所使用的詞彙。

### 問題 2

元素 × 模式的分類本身提供什麼？

- A. 有保證的人格與未來人生道路。
- B. 對命盤中每個天體的完整詮釋。
- C. 兩個傳統的星座面向，可以與其他命盤事實及明確說明的占星術方法一併考慮。
- D. 一個人的化學或物理性質。

**正確答案：**C。

**解釋：**元素與模式提供組織方式及詮釋提示，不是完整解讀，也不是經驗科學上的主張。

## 重點整理

每個黃道星座都有一種元素與一種模式：元素與模式為星座增加兩個不同的傳統面向，可以引導詮釋，但不會決定一個人。
