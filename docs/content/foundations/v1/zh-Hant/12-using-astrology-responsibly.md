# 負責任地使用占星術

## 導讀

Foundations 以一項實際責任作結：知道命盤結果支持什麼、詮釋增加什麼，以及什麼時候不應該提出某項主張。負責任的占星術讓語言與證據、方法、不確定性及能動性相稱；它既不是以恐懼為基礎的免責聲明，也不是要求人否定象徵。

學習者應該能夠留意過度主張、修復這種說法，並在結論需要猜測、診斷或不受支持的確定性時停止。

## 核心概念

### 詮釋是象徵性的、有脈絡的，而且不確定

占星術詮釋是透過某項傳統或方法進行的象徵性閱讀。它可能支持反思或敘事探索，但不會自動成為測量、因果解釋或預測。不同學派可能以不同方式強調同一個天體、星座、宮位或相位。

讓以下類別保持可見：

| 類別 | 例子 | 負責任的處理方式 |
| --- | --- | --- |
| **已知命盤事實** | 「回傳結果列出火星位於某個具名星座。」 | 按結果回報欄位，不增加缺失的脈絡。 |
| **不確定的輸入** | 「出生時間未知。」 | 保持限制可見，並抑制或限定依時間而定的主張。 |
| **詮釋慣例** | 「一種方法可能探索導向努力。」 | 說明這是可能的閱讀，不是發現出的特質。 |
| **推測** | 「這證明某人私生活中發生了什麼。」 | 不要把它呈現為結論。 |

信任邊界仍然是：**以天文學計算。透過占星術詮釋。**計算可以確立日期轉換、位置或角度關係；它不會在科學上驗證對該結構的詮釋。

### 精確不等於驗證

準確的時間轉換、天文位置、座標幾何、宮位建構與相位分隔，能讓計算忠實於輸入。這種精確不表示象徵會造成事件、測量人格或預測結果。仔細計算的命盤仍可能支持多於一種不確定的詮釋。

不要把科學詞彙當作裝飾。「結果回報四分相」屬於命盤幾何；「讀者可能探索壓力或努力」屬於詮釋。第一句的精確不會把第二句提升為科學。

### 用相稱語言取代決定論

避免「你注定會在職業上失敗」、「你永遠不會信任任何人」或「這個落點保證你的關係會結束」等說法。這些句子移除了脈絡與能動性。

負責任的語言不必聽起來機械。可用的形式包括「可能」、「可以被解讀為」、「一種可能的詮釋」、「在這張命盤的脈絡中」以及「結果沒有確立」。讀者應該能辨識事實、慣例與限制。

能動性與不確定性同樣重要。選擇、學習、環境、文化、關係、資源與情境共同形塑人生；象徵不應凌駕於它們之上，也不應揭露某個所謂固定的認同。

### 不要用占星術診斷或作出高風險決定

占星術不應診斷心理健康障礙、醫療狀況、創傷、神經多樣性、人格障礙、虐待、生育問題或疾病。命盤不是臨床評估、醫療檢驗，也不能替代合格的照護。

同樣的邊界適用於高風險決定。對醫療、心理健康、法律事務、財務決定或人身安全，不要鼓勵人以命盤取代合格的指導。負責任的閱讀可以承認一項疑慮，並指向適當的支持；它不應製造確定性。

當犯錯的後果很嚴重時，象徵性詮釋不能成為決策權威。

### 同意與第三方命盤

即使被稱為象徵，另一個人的出生資料或命盤仍可能揭示敏感脈絡。先詢問使用它是否適當，私下處理，也不要在沒有同意的情況下發布或傳播。不要對未參與的人推斷隱藏的醫療、心理健康、性、財務或關係資訊。

公開的出生資料不等於同意對名人作出侵入性的心理主張。公眾人物仍然是人，而不是推測的許可證。同樣的謹慎適用於伴侶、家人、同事與客戶。

兒童需要特別的克制。不要透過命盤為兒童貼標籤、預測固定的發展結果，或把象徵變成限制兒童未來可能性的工具。要把能動性、環境與持續變化的發展放在視野中。

### 知道什麼時候不要詮釋

當資料不可靠、必要的出生時間缺失、主張需要未回傳的欄位，或資訊過於單薄時，請暫停或婉拒。當要求涉及醫療、法律、財務、人身安全或其他高風險確定性，或要求你捏造命盤事實時，也應停止。

在證據邊界停止是正確的回應。說明已知內容，指出不可用的部分，並在不假裝已回答原始要求的情況下，提供較窄的反思問題。

### 責任不是否定

負責任的使用不要求把占星術稱為沒有意義。它容許一個詮釋框架，同時拒絕把它與因果科學、診斷、脅迫或確定性混淆。當閱讀透明地說明自己的狀態與限制時，人可以把命盤用於反思或開放式問題。

專業謙遜承認不同學派有所差異。當重點取決於學派時，請說「許多占星家」、「一種現代方法」或「某些傳統」。

## 專業詞彙

- **認識論狀態（Epistemic status）** — 一項陳述屬於什麼類型，以及它得到多少確定支持。
- **詮釋慣例（Interpretive convention）** — 某項傳統討論回傳命盤事實的象徵方式。
- **不確定性（Uncertainty）** — 輸入、計算狀態、可用欄位、方法或意義上的限制。
- **能動性（Agency）** — 一個人在情境中選擇、學習、回應與改變的能力。
- **同意（Consent）** — 使用或討論另一個人的出生資料或命盤時所需的適當許可。
- **敏感推論（Sensitive inference）** — 關於某人的個人結論，需要克制，且不應從象徵材料猜測。
- **相稱語言（Proportionate language）** — 信心程度與範圍符合支持事實的措辭。
- **責任邊界（Responsible boundary）** — 讀者應限定、縮小或拒絕詮釋的清楚界線。

## 範例

以下對照例子討論語言，不是某個人的命盤，也不是預測。

**過度主張：**「這個土星落點證明你將在職業上失敗。」

**負責任的改寫：**「一種占星術方法可能透過責任、限制或持續努力的主題來討論這個回傳的土星落點；單獨的落點不能確立職業結果，而當事人的情境與選擇很重要。」

這個改寫指出落點是回傳資訊，把意義標示為一種方法，並拒絕保證的結果。它也沒有保證成功。命盤可以開啟反思問題，卻不能決定某人必須做什麼。

再考慮一個要求：「請使用這張命盤告訴我，我的伴侶是否有心理健康障礙。」負責任的回應不是在命盤中尋找更謹慎的診斷。應說明占星術不能診斷心理健康狀況，保護伴侶的隱私，並把這項疑慮指向合格的專業支持。如果要求涉及兒童的未來，不要以聽起來較柔和的固定標籤取代診斷；要讓兒童的發展保持開放。

## 我的命盤

只有把**我的命盤**當作觀察回傳結果及其限制的機會時，才開啟它。

- **命盤存在：**區分輸入記錄、計算欄位、警告與任何詮釋句子。使用所選方法與受支持欄位；不要主張超過結果所能提供的確定性。
- **命盤存在但時間不完整或未知：**保持該狀態可見，不要作出需要被抑制的宮位、角點、宮頭或其他時間敏感事實的結論。
- **命盤不存在：**使用正常的命盤輸入邊界或本課的語言範例。不要從猜測建立個人命盤，也不要推斷另一個人的私密事實。

這條我的命盤路徑是責任檢查，不是診斷器、決策器或瀏覽器端的詮釋引擎。

## 練習

將每一項陳述分類為**回傳事實**、**詮釋慣例**、**不確定性**、**不受支持的過度主張**或**責任邊界**：

1. 「結果將出生時間標示為未知。」
2. 「一種方法可能透過回傳的土星落點探索責任主題。」
3. 「這張命盤證明當事人的伴侶不忠。」
4. 「要求的醫療結論超出命盤可以負責任地確立的範圍。」
5. 「結果列出兩個具名天體之間有四分相。」

接著用自己的話修復一項過度主張。如果可能，保留其中有用的問題，但移除確定性、診斷、脅迫或捏造的事實。對第三方命盤，先加入同意與隱私問題，再進行詮釋。

參考方向：說出已知內容、慣例內容、缺失內容，以及不應推斷的內容。負責任的回答可以尊重占星術，同時清楚說明它的限制。

## 理解檢核

### 問題 1

當有人要求占星術診斷伴侶的心理健康狀況時，負責任的回應是什麼？

- A. 使用更戲劇性的相位，讓診斷聽起來更有說服力。
- B. 如果出生時間準確，就提供一個暫定診斷。
- C. 說明命盤不能診斷心理健康狀況，避免對第三方作敏感推論，並將疑慮指向合格的專業支持。
- D. 從當事人的太陽星座推斷狀況。

**正確答案：**C。

**解釋：**命盤不是臨床評估，而計算準確也不會改變這項邊界。保護第三方隱私，並把嚴重疑慮指向合格支持，是負責任的限制。

### 問題 2

哪一項陳述把天文學與占星術保持在不同的證據分層？

- A. 精確的天文位置證明占星術詮釋必然為真。
- B. 天文學可以支持計算出的命盤結構，而占星術意義仍然是有脈絡的慣例，不會因此成為科學驗證。
- C. 象徵性詮釋是對人格的天文測量。
- D. 只要詮釋感覺有意義，就不需要記錄任何輸入或不確定性。

**正確答案：**B。

**解釋：**計算與詮釋回答不同問題。技術準確性支持被回報的結構；它不確立象徵意義是因果、客觀或經科學驗證的。

## 重點整理

負責任地使用占星術，意味著區分事實與慣例，讓不確定性與能動性保持可見，保護同意與隱私，拒絕診斷或高風險確定性，並在要求不受支持時停止。責任為詮釋設下界線，但不要求否定反思。
