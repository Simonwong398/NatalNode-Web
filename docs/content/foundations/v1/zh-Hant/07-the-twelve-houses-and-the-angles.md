# 十二宮位與角點

## 導讀

星座整理黃道周圍的位置。宮位將命盤空間分成十二個區段，而角點則標示這張地圖中四個重要、對時間與地點敏感的參考點。本課加入宮位層，同時不把它與星座、天體或預測混淆。

學完本課後，你應該能夠解釋宮位層、說出四個角點與兩條軸線、辨認 NatalNode 使用的三種入門宮位系統，並說明可靠的出生時間與地點為何重要。這是一張地圖，不是十二句固定的人生判決。

## 核心概念

### 宮位是命盤空間的區段

宮位是占星術用來整理生活領域脈絡的十二個有序區段之一。它不是行星、物理區域或天文物體。星座是黃道框架中的區段，宮位是依慣例劃分的命盤空間區段，而天體則是被放置其中的命盤對象。這些層次可以相遇，但不會因此互相替代。

宮位主題是在問某個天體或模式可能在哪裡被強調，不是事件保證。根據所採用的占星術方法，這個脈絡可能涉及學習、家庭、工作、關係互動或公共生活。

### 簡明的十二宮位地圖

以下是入門領域，而不是決定論式描述。不同學派可能以不同方式細化或安排它們的優先順序。

| 宮位 | 入門慣例領域 |
| --- | --- |
| **第一宮** | 存在感、身體經驗、直接取向，以及進入情境的方式。 |
| **第二宮** | 資源、所有物、價值、支持，以及被持有的事物。 |
| **第三宮** | 溝通、學習、近距離移動、交流，以及熟悉的網絡。 |
| **第四宮** | 家、根源、私人基礎、家庭脈絡，以及安定感。 |
| **第五宮** | 創造力、遊戲、愉悅、表達，以及創作。 |
| **第六宮** | 日常練習、例行作息、服務、維護，以及普通需求。 |
| **第七宮** | 一對一關係、伴侶互動、協議，以及相遇。 |
| **第八宮** | 共享資源、信任、義務、依賴，以及轉變。 |
| **第九宮** | 高等學習、旅行、世界觀、意義，以及更寬廣的框架。 |
| **第十宮** | 公共角色、志業、可見度、責任，以及貢獻。 |
| **第十一宮** | 朋友、群體、網絡、共同計畫，以及集體參與。 |
| **第十二宮** | 退隱、獨處、隱藏或臨界的過程、釋放，以及較不明顯的事物。 |

這些是提問領域，不是結果。第七宮不會決定婚姻，第十宮不保證職業，而第八宮或第十二宮的落點也不是診斷。請問實際顯示了什麼、使用哪一項傳統，以及哪些脈絡重要。

### 角點是參考點與軸線

四個常用的角點是：

- **上升點（`ASC`）** — 命盤時刻與地點上，黃道與東方地平線的交點，作為上升的參考點。
- **下降點（`DSC`）** — 位於上升點對面的點，在這條軸線的西方地平線一側。
- **中天（`MC`）** — 黃道與當地子午線相交的上中天點；它不只是天文學上的天頂。
- **天底（`IC`）** — 位於中天對面的子午線軸線點，與下中天相關。

兩條軸線的關係是結構性的：

```text
ASC  ↔  DSC
MC   ↔  IC
```

**地平線**是當地可見／不可見的邊界。**子午線**是當地南北向的天球參考圓。這些幾何關係為角點定位；**天頂**則是正上方的方向。由於中天使用黃道與子午線的關係，「MC 等於天頂」是不準確的簡寫。

### 角點、宮頭、宮位與星座是不同詞彙

**宮頭**是宮位的邊界；宮位是邊界之間的區段；角點是當地地平線或子午線的參考點；星座則是黃道框架中的區段。有些呈現方式會把第一、第四、第七與第十宮的宮頭和四個角點連在一起，但不是每一個宮頭都是角點。

視系統而定，角點可能落在某個宮位之內，而不是位於該宮位的起點。請閱讀回傳的標籤與所選系統，不要把單一圖表當成普遍結構。

### 入門宮位系統

NatalNode 目前的入門選項是**普拉西德制**、**整宮制**與**等宮制**。

- **普拉西德制**是以時間為基礎的象限方法，其邊界會隨命盤時間、地點與緯度變化。
- **整宮制**將每一個完整的黃道星座視為一個宮位，第一宮從包含上升點的星座開始；精確的 ASC 或 MC 可以落在某個宮位之內。
- **等宮制**從上升點的度數開始，依序建立十二個各三十度的等分宮位。

宮位系統改變時，天體的黃道位置不會改變，但它的宮位歸屬可能改變。沒有任何系統被宣稱為科學上或普遍而言正確；請記錄正在使用哪一項慣例。

### 出生時間與地點不是這一層的可有可無細節

可靠的宮位與角點通常需要可靠的出生時間與地點：時間為當地天空定向，而地點提供地平線與子午線脈絡。大約的時間只能支持較低的精確度，未知時間則必須維持未知。

NatalNode 不應插入中午、午夜或其他人工時間來製造角點、宮頭或宮位。如果結果抑制了這些欄位，請保留該限制。受支持的天體或星座事實仍可能存在，但缺失的宮位層不能由猜測重建。

### 星座不是宮位

牡羊座到雙魚座與第一宮到第十二宮是兩種不同的排序。牡羊座不等於第一宮，金牛座不等於第二宮，雙魚座也不因定義而等於第十二宮；第一宮可以從任何星座開始。「自然黃道」比較最多只是標示式教學助記，不是普遍的命盤結構，也不能取代所選系統。

### 空宮仍然是宮位

如果某個宮位內沒有顯示天體，有時會稱為**空宮**。空宮不表示該宮位不存在或不重要：這個區段仍然是命盤的一部分，後續閱讀可以把它與其他回傳因素一起考慮。不需要進入進階守護星方法來修正這項誤解。

## 專業詞彙

- **宮位（House）** — 用於慣例性的生活領域脈絡的十二個命盤空間區段之一。
- **宮頭（House cusp）** — 宮位的邊界或起點。
- **宮位系統（House system）** — 劃分命盤空間為宮位的一項具名慣例。
- **上升點（`ASC`，Ascendant）** — 與黃道和東方地平線交點相關的角點。
- **下降點（`DSC`，Descendant）** — 位於上升點對面的西方地平線一側的點。
- **中天（`MC`，Midheaven）** — 與黃道和當地子午線上中天位置相關的角點。
- **天底（`IC`，Imum Coeli）** — 位於中天對面的子午線軸線點。
- **地平線（Horizon）** — 定向命盤的當地可見／不可見邊界。
- **子午線（Meridian）** — MC–IC 軸線使用的當地南北向天球參考圓。
- **天頂（Zenith）** — 正上方的方向，不是中天的另一個名稱。
- **空宮（Empty house）** — 沒有顯示命盤天體的宮位，不是不存在的生活領域。

## 範例

使用以下合成教學卡片作為結構範例；它不是某個人的真實命盤，也不是 NatalNode 的計算結果：

- ASC：雙子座 14°；
- DSC：射手座 14°；
- MC：水瓶座 3°；
- IC：獅子座 3°；以及
- 顯示有一個命盤天體位於第六宮。

前四個標籤形成兩條相對軸線。最後一項是宮位落點，不是角點，也不是工作事件的保證。另一種宮位系統可能改變脈絡上的宮位歸屬，但不會改變天體的黃道位置。

如果記錄沒有可靠的出生時間，請移除角點與宮位主張，或將它們標記為不可用。不要重用雙子座 14°、選擇中午，或為了讓卡片看起來完整而保留第六宮標籤。只繼續處理受支持的天體／星座事實。

## 我的命盤

只有在命盤結果存在時才開啟**我的命盤**，並從回傳的輸入狀態與所選宮位系統開始。

- **命盤存在且出生時間受支持：**找出回傳的角點、宮頭與宮位落點。在比較邊界前先記下系統，並把宮位視為脈絡，而不是事件保證。
- **命盤存在但出生時間未知：**讓未知狀態保持可見。除非結果明確支持，否則不要加入 ASC、DSC、MC、IC、宮頭、宮位或以宮位為基礎的詮釋。繼續使用受支持的非宮位事實。
- **命盤不存在：**如果需要個人結果，使用正常的建立或計算邊界。不要輸入猜測的時間，也不要從星座推斷宮位。

這條我的命盤路徑是觀察受支持結構的邊界，不是授權課程或瀏覽器計算角點或宮位。

## 練習

請為每一項辨識命盤層次，並加上相關限制：

1. 將「ASC 14° 雙子座」分類為星座、天體、宮位、宮頭或角點。
2. 說明位於水瓶座 3° 的 MC 對面是哪一個點，並核對經度分隔。
3. 說出第四宮的一個慣例領域，並把它改寫成不會變成預測的句子。
4. 解釋第一宮從牡羊座開始為何可能但不是必要條件。
5. 如果結果標示出生時間未知並省略宮位，寫出讀者應採用的安全下一句。

參考答案：1. 角點；2. 獅子座 3° 的 IC，兩者相隔 180°；3. 可以考慮家或根源，但沒有事件受到保證；4. 星座與宮位不同；5. 宮位層不可用或受到限制，因此不要替換成某個時間。空宮仍然有效。

## 理解檢核

### 問題 1

哪一項陳述正確區分星座、宮位與天體？

- A. 牡羊座永遠是第一宮，而行星與它所在的宮位是同一件事。
- B. 星座是黃道框架中的區段，宮位是命盤空間的區段，而天體是可以在兩者中描述其落點的命盤對象。
- C. 宮位是繞著地球運行的天文物體。
- D. 宮位系統會改變天體計算出的黃道經度。

**正確答案：**B。

**解釋：**這些層次回答不同問題。宮位系統整理命盤空間，不會把星座變成宮位，也不會改變回傳的天體位置。

### 問題 2

當出生時間未知且命盤沒有回傳宮位或角點時，負責任的做法是什麼？

- A. 代入中午，讓命盤可以顯示每一層。
- B. 使用當事人的太陽星座推斷上升點。
- C. 保持時間未知，使用受支持的事實，並讓依時間而定的宮位與角點主張維持不可用或加上限定。
- D. 把每一個宮位都視為空宮，並結論說沒有任何生活領域重要。

**正確答案：**C。

**解釋：**未知時間會限制主張，但不授權捏造時間、猜測角點，或把省略的宮位解讀成沒有意義。

## 重點整理

宮位整理十二個命盤空間脈絡；ASC、DSC、MC 與 IC 形成兩條對時間與地點敏感的軸線。星座、宮位、天體、宮頭與角點保持區分，而未知時間不得被猜測填補。
