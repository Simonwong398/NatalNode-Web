# アスペクト：天体同士の関係

## オリエンテーション

アスペクトは、チャート上の二つの位置の角度関係です。幾何学のもう一つの層であり、それだけで人が「何者か」を示したり、角度を良い・悪いに変えたりするものではありません。正確に読むには、角度、オーブ、解釈を分けます。

この課では、入門として五つの関係を扱い、占星術の伝統で使われる名前を専門語彙として保ちます。

## 中心となる考え方

### 五つの角度関係

| おおよその角度 | 一般的なアスペクト名 |
| ---: | --- |
| 0° | コンジャンクション |
| 60° | セクスタイル |
| 90° | スクエア |
| 120° | トライン |
| 180° | オポジション |

角度はチャート上の幾何学的な事実です。コンジャンクションが自動的に調和を意味するわけではありません。スクエアが自動的に悪いわけでも、トラインが成功を保証するわけでも、オポジションが葛藤を運命づけるわけでもありません。

### オーブとアスペクトの位相

オーブは、正確な角度と、伝統が意味のある関係として扱う範囲との差です。結果には、必要に応じてオーブと方法を明示します。「アプライング」「正確」「セパレーティング」は、選んだ時間上の慣例に従い、関係が正確な点に近づいているか、一致しているか、離れているかを表します。

オーブ内のアスペクトと、正確な角度関係を混同しないでください。オーブを決める方法上の判断も、普遍的な天文学上の事実ではありません。

### 道徳的な評価をせず関係を読む

アスペクトは、チャートの二つのテーマがどう関係するかを問う助けになります。可能な解釈では、天体、サイン、裏づけのあるハウス、オーブ、文脈を考えます。幾何学は対話を整理しますが、人の人生を肯定・否定に分類しません。

## 専門用語

- **アスペクト** — チャート上の二つの位置の角度関係。
- **コンジャンクション** — 0°に近い関係。
- **セクスタイル** — 60°に近い関係。
- **スクエア** — 90°に近い関係。
- **トライン** — 120°に近い関係。
- **オポジション** — 180°に近い関係。
- **オーブ** — 方法に応じて正確な角度から許容される距離。
- **アプライング** — 時間上の慣例に従って正確な点に近づく関係。
- **正確** — 基準となる角度と一致する関係。
- **セパレーティング** — 同じ慣例に従って正確な点から離れる関係。

これらの名前は幾何学と方法を表します。それ自体に道徳的評価は含まれません。

## 例

実在のチャートではない合成された学習用カードが、次の正確な関係を示しています。

- 太陽は牡牛座20°（50°）、水星は牡牛座22°（52°）：2°のコンジャンクション。
- 太陽は牡羊座10°（10°）、月は天秤座10°（190°）：オポジション。
- 火星は蟹座15°（105°）、土星は天秤座15°（195°）：スクエア。
- 金星は獅子座12°（132°）、木星は射手座12°（252°）：トライン。
- 水星は双子座5°（65°）、金星は獅子座5°（125°）：セクスタイル。

度数と黄経が幾何学を示します。「スクエア」や「トライン」という語だけから、その関係が悪い・良いと結論してはいけません。

## マイチャート

**マイチャート**を開き、表示されたアスペクトごとに次を記録します。

- 関係する二つの天体。
- 角度の間隔、またはアスペクト名。
- 表示されていればオーブ。
- 方法がアプライング、正確、セパレーティングのどれとして表示しているか。

その後、関係について開かれた問いを作ります。どの天体が関わるかを知らずにアスペクトを使わず、アスペクトがないことから個人について結論しないでください。

## 練習

合成カードの次の間隔を計算し、アスペクト名を答えてください：50°–52°、10°–190°、105°–195°、132°–252°、65°–125°。必要なら円周上の短い距離を使います。

参考解答：2°のコンジャンクション、180°のオポジション、90°のスクエア、120°のトライン、60°のセクスタイル。これは幾何学の練習であり、良い・悪いの値をつける練習ではありません。

## 理解度チェック

### 問題 1

二つの天体がスクエアを形成することは、主に何を意味しますか。

- A. その人には不運がある。
- B. 明示されたアスペクト体系で、位置が90°に近い角度関係にあること。可能な意味は解釈と文脈を必要とする。
- C. どちらかの天体を計算から削除する必要がある。
- D. 人格の科学的な測定である。

**正解：** B。

**解説：** スクエアはおおよその幾何学を名づけます。後の対話にはオーブ、方法、関係する天体が重要ですが、判定を作るわけではありません。

### 問題 2

正確なアスペクトとオーブ内のアスペクトの違いはどれですか。

- A. 正確なものは常に良く、もう一つは常に悪い。
- B. 正確なものは基準角度と一致し、もう一つは方法が許す距離の中にある。
- C. 違いはない。オーブは人格を測るものだからである。
- D. オーブ内のアスペクトはチャートに表示できない。

**正解：** B。

**解説：** オーブは正確な角度からの距離についての方法上の判断です。道徳的な評価や個人の原因と混同してはいけません。

## 要点

アスペクトは角度関係です。角度、オーブ、位相が構造を説明し、意味は文脈のある解釈になります。良い・悪いの尺度ではありません。
