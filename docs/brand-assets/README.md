# NatalNode brand assets

This directory is the archive index for the approved NatalNode brand system.
The production SVG sources live in `apps/web/public/brand/` so Astro can serve
them as stable first-party assets. The reusable inline implementation lives in
`apps/web/src/components/brand/`.

## Source inventory

- `natalnode-mark.svg` — default midnight navy and signal cyan Core Mark.
- `natalnode-mark-dark.svg` — white and signal cyan Core Mark for dark surfaces.
- `natalnode-mark-light.svg` — midnight navy and signal cyan Core Mark for light surfaces.
- `natalnode-mark-black.svg` — one-color black Core Mark.
- `natalnode-mark-white.svg` — one-color white Core Mark.
- `natalnode-lockup-horizontal.svg` — dark-surface horizontal lockup.
- `natalnode-lockup-horizontal-dark.svg` — dark-surface horizontal lockup.
- `natalnode-lockup-horizontal-light.svg` — light-surface horizontal lockup.
- `../../apps/web/public/favicon.svg` — installed site favicon using the Core Mark.

No raster icon, font binary, or generated design-tool file is required by the
current website architecture.
